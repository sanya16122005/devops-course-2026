# Цели на семестр

1. **Освоить Docker на практике.** Научиться писать Dockerfile и docker-compose.yml,
   упаковать собственное веб-приложение в контейнер и запустить его связкой
   «приложение + база данных» одной командой.

2. **Собрать рабочий CI/CD-пайплайн.** Настроить GitHub Actions так, чтобы при каждом
   Pull Request автоматически запускались линтер и тесты, а при merge в main
   происходил автоматический деплой.

3. **Уверенно работать в Linux из терминала.** Научиться администрировать
   удалённый сервер по SSH: писать bash-скрипты, настраивать systemd-юниты
   и разбирать логи через journalctl.
