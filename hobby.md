# Мой пет-проект

Идея: сайт-визитка (портфолио) — одностраничный сайт с моими проектами,
навыками и контактами. Хочу довести его до состояния, когда он автоматически
пересобирается и деплоится при каждом пуше в main.

Стек: HTML / CSS / JavaScript, хостинг на GitHub Pages, сборка через GitHub Actions.

Цель: научиться настраивать автоматический деплой статического сайта из репозитория —
то есть пройти полный путь от коммита до продакшена своими руками.

## Сроки реализации

- **Неделя 1–2.** Свёрстать одностраничный макет: секции «Обо мне», «Проекты»,
  «Навыки», «Контакты». Адаптив под мобильные.
- **Неделя 3.** Выложить сайт на GitHub Pages вручную, проверить, что домен
  открывается и стили не разъезжаются.
- **Неделя 4.** Настроить GitHub Actions: workflow, который при пуше в `main`
  собирает сайт и публикует его на Pages без моего участия.
- **Неделя 5.** Добавить в пайплайн проверку качества — линтер HTML/CSS
  и падение сборки при битых ссылках.

**Критерий готовности:** я пушу коммит в `main` и через пару минут вижу изменения
на живом сайте, не открывая ничего, кроме терминала.
